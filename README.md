# 네이버 블로그 맛집 자동 작성기 (Naver Blog Auto-Poster) 🍖✨

네이버 블로그 스마트에디터 ONE에 **1,500~2,500자의 정성스러운 장문 맛집 리뷰**를 고속 자동 작성해주는 프로그램입니다.
최신 핫플레이스 자동 추천, 사진 자동 수집 및 콜라주(가로 나란히) 배치, 네이버 지도·가게정보 최상단 삽입, 스티커 삽입까지 원클릭으로 지원합니다.

---

## 📌 주요 특징 및 기능

1. **🔥 최신 핫플레이스 50곳 자동 추천 & 중복 작성 방지**:
   - 성수동, 용리단길, 힙지로, 도산공원, 연남동 등 2025~2026 최신 핫플레이스 50곳 엄선 내장
   - **한 번 작성한 식당은 영구 기록되어 다음 추천 풀에서 자동 제외** (중복 포스팅 원천 방지)
   - 작성 이력 관리 창(written_history.json)을 통해 작성 목록 확인, 개별 복구, 전체 초기화 지원

2. **📸 사진 자동 수집 vs 내 사진 직접 넣기 (콜라주 가로 배치)**:
   - **자동생성 모드**: 네이버에서 글자/워터마크 없는 찐 실사 12~14장을 자동 수집하여 2장씩 가로 나란히(콜라주) 자동 배치
   - **직접 넣기 모드**: 사용자가 찍은 사진 파일명(외관, 내부, 메뉴판, 상차림, 음식 등)을 100% 자동 인식하여 글 문맥과 1:1 완벽 매칭 배치

3. **🗺️ 실제 매장 정보 & 네이버 지도 최상단 자동 첨부**:
   - 네이버 플레이스에서 전화번호, 주소, 영업시간, 주차 정보 자동 크롤링
   - 스마트에디터 장소 카드 자동 검색 및 본문 최상단 첨부

4. **⚡ CDP 직접 키스트로크 타이핑 (클립보드 무관 100% 보장)**:
   - 클립보드(Ctrl+V) 붙여넣기 오류를 탈피하고 Chrome DevTools 직접 타이핑으로 오타/누락 없이 고속 자동 타이핑
   - 제목과 본문 완벽 분리, 네이버 감성의 가운데 정렬 기본 적용
   - 취소선(가로줄) 오작동 방지 및 자동 해제 탑재

5. **🎀 네이버 스티커(OGQ) 자동 삽입 & 2030 감성 블로거 말투**:
   - 글자 중간 끊김 없이 독립 문단에 스티커 자동 배치
   - 친근하고 생생한 '했어요!' 말투 & 풍부한 감탄사(!)

6. **🔒 네이버 로그인 세션 영구 보존**:
   - 최초 1회 브라우저 로그인 세션을 로컬에 안전하게 보존하여 매번 로그인할 필요 없음
   - 개인정보(
aver_profile)는 .gitignore로 보호되어 Git에 업로드되지 않음

## 🛠️ 설치 및 실행 방법

### 1. 저장소 클론 및 패키지 설치
`ash
git clone https://github.com/사용자아이디/naver-blog-bot.git
cd naver-blog-bot
pip install -r requirements.txt
playwright install chromium
`

### 2. 프로그램 실행
`ash
python app.py
`
*(또는 Windows에서 
un.bat 더블 클릭)*
